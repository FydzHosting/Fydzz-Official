Code Sandbox & Guide Termux

Langkah cepat menjalankan Express.js Server di aplikasi Termux Android: 

# 1. Update paket & Install Node.js
pkg update && pkg upgrade -y
pkg install nodejs git -y

# 2. Buat folder proyek & jalankan npm init
mkdir my-server && cd my-server
npm init -y
npm install express

# 3. Jalankan aplikasi Express
node index.js
